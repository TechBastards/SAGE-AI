# Project Objectives & Targets

## 1. Functional Objectives
*   **Continuous Capture:** Enable stable 15-second visual and auditory recording cycles.
*   **Automatic Handshake:** Enable automatic Wi-Fi connection and file download sequences on the mobile client.
*   **Semantic Timeline:** Build an interactive chronology of user events with titles, summaries, and tags.
*   **Conversational Assistant:** Provide natural language query capabilities to retrieve memories.

---

## 2. Technical Performance Requirements
*   **Zero-Loss Buffer:** Maintain stable audio recording at 16kHz and video capture at >=10 FPS.
*   **Transmission Efficiency:** Download both video and audio buffers from the hardware to the phone in under 8 seconds.
*   **Storage Economy:** Mux visual and auditory channels into compressed MP4 files to reduce storage usage.
*   **Battery Preservation:** Power down the camera sensor and lower core frequencies when idle.
